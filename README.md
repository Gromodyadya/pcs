### 1. Краткое описание проекта и назначение приложения

**Название приложения:** AutoHub
**Технологический стек:** Flutter (Dart), Supabase (PostgreSQL, Auth, Storage).

**Назначение:**
AutoHub — это кроссплатформенное мобильное приложение, предназначенное для автоматизации работы автосалонов и удобного поиска автомобилей покупателями.

**Основные функции:**
*   **Для пользователей:** Просмотр каталога автосалонов, фильтрация по городу, марке и году выпуска, просмотр детальной информации об автомобилях.
*   **Для бизнеса:** Регистрация владельца автосалона, создание и редактирование профиля салона, управление складом автомобилей (добавление, редактирование, удаление), загрузка фотографий.
*   **Безопасность:** Разграничение прав доступа (RLS) для защиты данных.

### 6. Содержание документов

#### 6.1. README.md
```markdown
# AutoHub - Мобильное приложение для автосалонов

## Описание
AutoHub — это кроссплатформенное мобильное приложение для управления автосалонами и продажи автомобилей. Приложение позволяет владельцам бизнеса управлять своими салонами и автомобилями, а покупателям — искать и просматривать доступные авто.

## Стек технологий
- **Фреймворк:** Flutter (Dart)
- **Backend & Database:** Supabase (PostgreSQL)
- **Архитектура:** Feature-first

## Основные функции
1. **Авторизация:** Вход и регистрация через Email.
2. **Роли:** Разделение прав доступа (Владелец салона / Пользователь).
3. **Управление салонами:** Создание, редактирование, удаление (CRUD).
4. **Управление авто:** Добавление фото, цены, характеристик.
5. **Поиск и фильтры:** Фильтрация по городу, марке, году выпуска.
6. **Безопасность:** RLS (Row Level Security) для защиты данных.

## Установка и запуск
1. Клонировать репозиторий.
2. Выполнить `flutter pub get`.
3. Настроить `lib/main.dart` с вашими ключами Supabase.
4. Запустить `flutter run`.
```

### Вывод
В ходе выполнения практической работы приложение AutoHub было полностью подготовлено к публикации.
1.  Сгенерирована цифровая подпись (`.jks`), настроена конфигурация сборки `release`.
2.  Создан установочный файл `app-release.apk`, оптимизированный для Android (размер ~55 МБ).
3.  Подготовлен полный пакет документации и графических материалов (иконки, скриншоты).

**Обнаруженные сложности:**
В процессе работы возникли сложности с настройкой путей к утилите `keytool` в Windows PowerShell, а также конфликты синтаксиса в `build.gradle.kts` (Kotlin DSL) при настройке подписи. Проблемы были решены путем указания полного пути к Java и переписывания конфигурации Gradle на Kotlin.

Приложение готово к загрузке в магазин приложений RuStore.
